# rust2cython playground

1. Run `cargo build --release` in the repository root.
2. Run `RUST2CYTHON_BIN=./target/release/rust2cython python3 playground/server.py`.
3. Open <http://localhost:7331>.

This uses the same backend as the hosted playground at [playground.rust2cython.dev](https://playground.rust2cython.dev) (URL placeholder until deployment).
